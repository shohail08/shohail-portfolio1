# Shohail Portfolio

This is the complete static portfolio.

## Files
- `index.html` — website
- `content.js` — the only file you need to edit for your email and projects
- `assets/pokemon-background-14s.mp4` — 14-second looping background
- `assets/charizard.gif` — animated pixel character

## Add your email
Open `content.js` and replace:
`YOUR_EMAIL_HERE`
with your email address.

## Add a project
Copy one object inside `projects`:
```js
{
  title: "My New Project",
  description: "Short description.",
  tags: ["PYTHON", "SQL"],
  link: "https://github.com/..."
}
```
The project card will appear automatically.

## Important
Keep the `assets` folder beside `index.html` when uploading to GitHub/Cloudflare Pages.
